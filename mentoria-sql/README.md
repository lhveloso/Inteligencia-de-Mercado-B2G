# Mentoria de SQL

Programa de estudo de 12 semanas para chegar pronto(a) em entrevistas técnicas de **Analista de Inteligência de Mercado**.

Comece por [`00-programa-do-curso.md`](00-programa-do-curso.md) para ver o roadmap completo, depois vá para [`semana-01/licao.md`](semana-01/licao.md).

Estrutura:
```
mentoria-sql/
├── 00-programa-do-curso.md   # roadmap das 12 semanas
├── dados/
│   ├── gerar_base.py         # script que gera a base de prática
│   ├── editais_b2g.db        # base SQLite pronta para uso
│   └── schema_seed.sql       # mesma base em SQL puro (portável)
└── semana-01/
    ├── licao.md
    ├── exercicios.sql
    ├── gabarito.sql
    └── entrevista.md
```

Novas semanas são adicionadas conforme o progresso do aluno.
